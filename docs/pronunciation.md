# 发音

在「设置 → 发音」管理来源。首次使用预置有道美音、有道英音和默认启用的 系统语音。有道美音与英音分别使用 `type=2` 与 `type=1`；各项可独立编辑、启停和删除。配置保存在本机，删除所有来源后不会自动恢复默认项。最多 33 项。新增来源默认分配随机颜色，避开所有现有来源（包括已禁用项）的颜色；首次预置的颜色也随机且互不重复，保存后保持不变。已有来源的颜色保持原值。

升级时一次性补入默认启用的系统语音来源，不覆盖原有来源。之后删除系统语音或将其关闭，重启后仍保持用户的选择。

每项来源及编辑窗口均有图标试听按钮，固定朗读 `hello`，支持试听尚未保存或未启用的来源。按钮占位固定，加载时原地显示进度，播放时原地显示停止图标；再次点击停止，结束后恢复播放图标。错误在同一位置显示红色提示图标，悬停可查看原因；没有额外的测试或重播文字按钮。测试共用应用播放服务，切换试听会停止旧音频；关闭设置或编辑窗口时释放所属试听资源。

URL 模板使用 `{text}`，例如：

```
https://dict.youdao.com/dictvoice?audio={text}&type=2
```

播放时使用当前输入框的原始完整内容，保留大小写、前后空白和换行；仅空白的输入不允许播放。替换内容按 URL 组成部分进行百分号编码，因此输入中的 `&`、`+`、`/`、`#` 等不会变成额外参数或路径分隔符。模板可在路径或参数中重复使用 `{text}`。来源必须使用 HTTPS，不接受用户名、密码、片段或在主机名中插入变量。

主窗口与取词浮窗底部均有发音按钮。悬停或点击打开来源列表，点击彩色扬声器播放并关闭列表。外层按钮显示加载、播放和失败状态。再次选择可重播或切换来源；加载和播放时可在列表内停止。修改输入、切换模式、隐藏所属窗口，或编辑、禁用、删除当前来源时，停止并释放音频。

主窗口、取词浮窗与设置试听共用一个播放服务，避免同时播放。远程来源与系统 TTS 使用同一套状态与资源清理逻辑。播放服务按需创建 AVPlayer，使用流式播放与较小的预缓冲，不缓存音频；停止时移除观察者、通知、超时任务并释放当前媒体。异步回调用请求代次校验，避免旧播放器更新新请求。加载或缓冲超过 30 秒报错，单次持续播放上限为 5 分钟，失败后可以立即重试。

点击远程来源时才向对应服务发送当前文字，悬停不发送请求。系统来源使用 `AVSpeechSynthesizer` 与已安装的对应语言语音，按需创建并释放语音合成器，不向配置的远程服务发送文字。

系统语音接口从 macOS 10.14 起提供，覆盖项目支持的 macOS 12 及以上系统，不依赖较新系统的 Personal Voice 或 Siri API。编辑系统来源时，可设置语言（自动识别或指定语言）、声音（不限/男声/女声）、具体角色和语速（0.5–1.5 倍）。角色列表只包含本机已安装、符合当前语言和声音选项的语音，显示角色名、语言及系统提供的性别信息。系统未标注性别的角色在「不限」下可选，不根据角色名推断性别。下载语音后可手动刷新列表。

指定角色后，实际播放与 hello 试听使用同一角色和语速；没有指定角色时，自动选择符合语言和声音设置的语音。自动识别模式优先匹配文字语言（英语优先美音，简体/繁体中文分别优先大陆/台湾语音）。所选角色已不可用时明确报错并提示重新选择，不静默替换。旧配置缺少这些字段时沿用自动选择、性别不限和原有 0.85 倍语速。旧默认名称「macOS 系统语音」自动改为「系统语音」，保留自定义名称。语音启动有超时保护，取消与完成的回调按合成器和语句身份检查，防止旧回调干扰新播放。

## 验证

按协作约定，先取得用户对测试方案的同意，再运行检查或操作界面。

- `sh scripts/build-release.sh`：沿用项目开发签名，编译 macOS 12 起支持的 arm64、x86_64 Release。
- `sh scripts/check-pronunciation.sh`：独立偏好设置域，无远程请求；检查模板编码、默认项、随机颜色去重、旧配置迁移、系统语音删除后不恢复、固定试听文本、语音设置持久化、角色筛选、默认名称迁移、无效 URL、配置持久化、删除后空列表、数量上限以及无效请求清理；不实际启动 TTS。
- `sh scripts/check-lookup.sh`、`sh scripts/check-ai.sh`、`sh scripts/check-ai-history.sh`：相关现有逻辑回归。
- 实际界面：检查两个窗口的悬停与点击、来源颜色、加载和播放状态、快速切换与重播、空输入、网络失败恢复、禁用/删除当前来源及关闭窗口停止播放。编译与本地检查不代表这些真实音频交互已经验证。
