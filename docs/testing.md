# 检查与验证

本文列出可用入口，不代表这些检查已在当前提交执行或通过。与自动化助手协作时，先说明将运行的检查、外部访问、文件影响和是否启动界面，取得用户同意后再执行。Release 编译按项目约定自动执行，与测试批准分开。

## 独立逻辑检查

在仓库根目录执行，各脚本先编译对应的独立检查程序，再运行，产物位于 `build/Checks/`。脚本链接某个生产服务类型不等于会调用真实服务；新增用例仍须核对依赖和数据流。

| 入口 | 主要范围 | 外部条件与影响 |
| --- | --- | --- |
| `sh scripts/check-device-identifier.sh` | 固定跨语言设备 ID 向量、大小写规范化及无效 UUID | 仅合成输入；不读取硬件、Keychain，不联网 |
| `sh scripts/check-lookup.sh` | 查询状态、候选、取消及结果复用 | 模拟服务与隔离偏好，不需真实词典 API |
| `sh scripts/check-runtime.sh` | HTTP 边界、配置、限流等 | 模拟传输/服务，不需真实凭据 |
| `sh scripts/check-ai-settings.sh` | AI 配置与设置状态 | 模拟服务，不验证真实提供商 |
| `sh scripts/check-ai.sh` | AI 查询、流式解码与取消 | 模拟响应，不发起付费请求 |
| `sh scripts/check-ai-history.sh` | AI 历史读写、恢复、清理及状态 | 测试目录文件和隔离偏好，不使用正式历史目录 |
| `sh scripts/check-local-dictionaries.sh` | 本地格式、路由、资源、文档及边界 | 默认使用自制 MDX、临时文件和模拟在线服务；附加词典根目录参数才检查真实词典 |
| `swift test --package-path Packages/HoverLookupKit` | 独立取词包的管线、取消、安全阻断与请求门控 | 以具体测试源码为准；不等于真实应用兼容性验证 |

## OCR、捕获与外部数据

- `sh scripts/check-hover.sh`：包含生成图片及实际 Vision OCR、分词和坐标检查；系统可能按需初始化识别模型。
- `sh scripts/check-capture.sh`：捕获协调、取消、权限替身和坐标等独立检查；不代表已对真实屏幕和系统授权验证。
- `sh scripts/check-candidate-redirects.sh /path/to/dictionaries`：依赖检查源码约定的具体真实词典和词条，必须显式传入词库根目录；该目录下需有 `LDOCE6++.En-Cn.V3-0` 子目录及对应 MDX。缺少参数时直接提示用法，不读取任何默认本机目录。这不是任意机器可运行的通用检查，不纳入默认公共检查集合。
- `sh scripts/check-ai-ollama.sh`：真实请求本机 `localhost:11434` 的 `qwen3.5:9b`，不使用已保存密钥；需要本机服务及模型，会占用推理资源，须单独选择执行。

真实词典只读取合法持有的本机副本，不将商业词库上传仓库或 CI。真实 AI 或在线 API 验证应单独说明提供商、请求范围和可能费用。

## 界面、权限与跨应用验证

独立界面预览应用及其构建入口已移除。界面验证直接使用正式应用；启动应用、操作真实界面与读取屏幕仍属于需单独批准的验证，不随逻辑检查自动执行。

建议验收：菜单栏显示/收起、输入法、键盘候选、窗口关闭/固定位置、取词模式与草稿、AI 停止及历史、词典样式/链接/音频、深浅色与支持系统回退。权限及取词另测首次授权、拒绝、撤销、重启、不同来源应用、全屏、Space、Retina/多显示器和安全输入。不要在未授权时捕获用户屏幕或读取其他应用内容。

## 内存与结果报告

分别记录空闲、首次打开、重复查询、本地 WebKit、OCR/AI、关闭窗口及退出前后的资源情况；区分应用进程与系统/网页内容进程。报告工具、系统、构建类型、场景和采样时间。缓存字节上限是内容估算，不是整个应用的内存上限。

当前 Xcode scheme 没有配置应用测试 target；应用逻辑检查使用上面的独立脚本，不能假定 `xcodebuild test` 会覆盖它们。自动检查流程尚未随本文创建。每次交付应明确哪些已执行、哪些仅阅读源码、哪些尚未验证。
