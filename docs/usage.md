# 使用与排障

## 查询和窗口

从菜单栏打开手动窗口，在原来模式标签的位置选择翻译方式：自动选择翻译方式、ODict 在线词典、macOS 系统词典、每一本 MDX 或 AI 翻译。取词窗口的同一选择器位于底部。主界面和取词共用当前选择，仅在本次应用会话内保留，重启后默认自动选择翻译方式。切换时保留原文：已提交内容立即恢复已保存结果或查询，未提交草稿只改变方式。AI 输入使用回车提交、Shift + Enter 换行，生成时原文只读，可停止和编辑。

手动窗口用于输入、候选和历史；取词窗口用于结果、固定位置和关闭。图钉固定的是取词窗口位置，不是永久显示或阻止所有取消行为。具体隐藏和请求取消以当前操作及来源状态为准。

取词失败或未识别到文字时，提示页只说明原因，不提供重新截图、重新取词或重试按钮。关闭窗口后，按取词快捷键重新操作；权限与识别引擎问题需先按提示处理。AI 翻译确认页仅保留本次翻译或服务配置入口。取词、查询和 AI 状态提示共用标题、说明、原文区域及按钮样式；AI 请求失败后的重新生成只使用已有原文，不会重新取词。

候选使用方向键选择、回车确认。全局快捷键默认不占用，需要在设置中录制。没有 Dock 图标时，可通过菜单栏进入设置或退出。

## 权限

选中取词需要辅助功能；截图及悬停 OCR 需要屏幕录制。在系统设置中授权后返回应用，并重新触发操作；系统提示需重启时按提示执行。拒绝权限不会阻止手动输入查询。

选中取词不模拟复制；部分应用不提供可读选区或鼠标处文字，可改用截图。截图支持单个显示器内框选，不支持跨屏拼接；Escape 取消。悬停默认关闭，启用后可选择修饰键或不使用辅助键；触发停留时间不等于 OCR 和网络查询总延迟。

升级或更换构建后权限异常时，先确认只运行一个 ODict 副本、位置固定、Team/Bundle ID/签名类型是否变化；必要时在系统设置重新授权。不要通过关闭签名处理权限问题。

## 本地词典

先核对 MDX/MDD 支持格式、资源包关联和外置磁盘可用性，再检查词典目录的 CSS/JS 覆盖。只删除应用中的词典配置不会删除原词库。详情见 [本地词典说明](local-dictionaries.md)。

未登录时仍可使用本地词典。“自动选择翻译方式”可能继续进入在线路径；直接选择某本 MDX 或系统词典时，只查询指定来源，不自动联网回退。中文反查依赖在线接口。

## 网络和 AI

在线词典需要在账号区域登录，通过网页授权后自动取得凭证。凭证临近到期时按需刷新；查询遇到 401 时最多刷新并重试一次，刷新无效则重新登录。403 检查服务权限与网关来源规则，404 检查词条和部署前缀，429 按界面提示等待。客户端不无限重试请求；旧产品只读密钥已停用。

账号资料在网页点击头像后编辑，包括昵称、性别、预设头像和密码。网页修改或重置密码会撤销全部会话，Mac 也需重新登录。启动统计可在“权限与隐私”关闭；关闭不影响登录与在线查询，不会删除已有统计或账号关联记录。

AI 地址需包含提供商需要的路径前缀或完整 `/chat/completions`；模型、思考参数和密钥必须由所选服务支持。连接验证可能产生费用，也不会代替保存。Ollama 需事先启动并准备模型。

“自动选择翻译方式”按「一般设置」中的已启用来源顺序查询，命中即停止。可能是句子时可在提交或取词后自动用 AI 翻译，也可先提示确认；直接选择具体词典时不会自动转用 AI，原文保持完整，不能查询长句时会提示切换方式。

「设置 → 一般设置 → 词典查询回退」可开启「识别到句子时自动用 AI 翻译」，默认关闭，保存后生效。开启后仅在提交 / 取词时自动发送，输入过程中不会自动调用 AI；未配置 AI 时仍显示配置入口。单词或短语未查到仍需确认。识别采用标点、长度和常见句式的近似规则，可能误判；OCR 换行视为空格，英文缩写和小数尽量保留为词语。每次 AI 输入最多 4000 字，超出时需分段。

## 本地日志

Debug 构建可按 `[ODict.Local]` 过滤本地词典诊断。`article` 标识同一词条展示，`t` 为诊断初始化后的毫秒数。典型流程为 `route.begin → lookup.begin → lookup.hit → route.local`，在线回退标记 `route.online`。

`ODICT_LOCAL_HTML` 可设为 `off`、`raw`、`document`、`both` 或 `full`。默认 `both` 的每阶段输出上限 256 KiB；`full` 会输出全文，可能包含受版权保护或隐私内容，也会增加控制台开销。`off` 只关闭 HTML 转储，流程日志仍可能含查询词和路径。Release 不包含这些 Debug HTML 转储。

反馈问题时遵循 [贡献指南](../CONTRIBUTING.md)，不要发送未脱敏日志或完整词库。


## 统一查询历史

清空输入后显示所有翻译方式共用的历史。同一原文按去掉首尾空白后的文本分组，保留大小写和内部换行；每种方式保留最近一次结果，列表展示最后选择的方式与摘要。打开记录恢复它最后使用的方式，不修改会话默认方式；主动选择方式才会修改会话默认方式。

在线词典保存完整结构化词条，系统词典保存完整文本，AI 保存完整 Markdown 或已生成的部分回答。MDX 保存词典标识、词条与简短摘要，打开时重新读取本机词典；来源移除或停用时显示提示，原文与其他方式的结果仍保留。切换到已保存方式不重复请求 AI；可通过「重新生成」更新该方式的结果。

历史数量统一按原文条数计算，默认 20，范围 0–100，0 表示不保留。结果文件每条上限 8 MB，同一原文最多 36 种方式、32 MB，总结果内容上限 128 MB。超出单组上限时移除较早方式的结果；超出原文数量或总内容上限时移除较早原文及其所有结果。历史索引与未写入队列也有独立上限，完整结果按需读取，隐藏窗口释放当前结果与渲染资源。

此版本使用新的统一历史目录，不导入旧的词典 / AI 历史，也不会修改旧历史文件。
