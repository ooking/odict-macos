# 使用与排障

## 查询和窗口

从菜单栏打开手动窗口，词典与 AI 各自保留输入草稿。切换到 AI 不会自动发送请求；回车提交，Shift + Enter 换行。取词模式在设置中单独选择，供选中、截图和悬停共用。

手动窗口用于输入、候选和历史；取词窗口用于结果、固定位置和关闭。图钉固定的是取词窗口位置，不是永久显示或阻止所有取消行为。具体隐藏和请求取消以当前操作及来源状态为准。

候选使用方向键选择、回车确认。全局快捷键默认不占用，需要在设置中录制。没有 Dock 图标时，可通过菜单栏进入设置或退出。

## 权限

选中取词需要辅助功能；截图及悬停 OCR 需要屏幕录制。在系统设置中授权后返回应用，并重新触发操作；系统提示需重启时按提示执行。拒绝权限不会阻止手动输入查询。

选中取词不模拟复制；部分应用不提供可读选区或鼠标处文字，可改用截图。截图支持单个显示器内框选，不支持跨屏拼接；Escape 取消。悬停默认关闭，启用后可选择修饰键或不使用辅助键；触发停留时间不等于 OCR 和网络查询总延迟。

升级或更换构建后权限异常时，先确认只运行一个 ODict 副本、位置固定、Team/Bundle ID/签名类型是否变化；必要时在系统设置重新授权。不要通过关闭签名处理权限问题。

## 本地词典

先核对 MDX/MDD 支持格式、资源包关联和外置磁盘可用性，再检查词典目录的 CSS/JS 覆盖。只删除应用中的词典配置不会删除原词库。详情见 [本地词典说明](local-dictionaries.md)。

未登录时本地命中仍可使用；未命中后可能提示登录，因为当前没有严格仅本地模式。中文反查依赖在线接口。

## 网络和 AI

在线词典需要在账号区域登录，通过网页授权后自动取得凭证。凭证临近到期时按需刷新；查询遇到 401 时最多刷新并重试一次，刷新无效则重新登录。403 检查服务权限与网关来源规则，404 检查词条和部署前缀，429 按界面提示等待。客户端不无限重试请求；旧产品只读密钥已停用。

账号资料在网页点击头像后编辑，包括昵称、性别、预设头像和密码。网页修改或重置密码会撤销全部会话，Mac 也需重新登录。启动统计可在“权限与隐私”关闭；关闭不影响登录与在线查询，不会删除已有统计或账号关联记录。

AI 地址需包含提供商需要的路径前缀或完整 `/chat/completions`；模型、思考参数和密钥必须由所选服务支持。连接验证可能产生费用，也不会代替保存。Ollama 需事先启动并准备模型。

词典模式下，截图、选中取词和手动提交的内容会先经过本地单词 / 短语判断；可能是句子时跳过词典请求，显示原文并询问是否仅本次用 AI 翻译。单词或短语未查到时也会显示原文和 AI 操作。确认后立即翻译，不改变手动或取词的默认模式；新查询仍按原模式处理。网络或鉴权失败仍显示原来的错误，不作为词典未收录处理。

「设置 → AI → 词典查询回退」可开启「识别到句子时自动用 AI 翻译」，默认关闭，保存后生效。开启后仅在提交 / 取词时自动发送，输入过程中不会自动调用 AI；未配置 AI 时仍显示配置入口。单词或短语未查到仍需确认。识别采用标点、长度和常见句式的近似规则，可能误判；OCR 换行视为空格，英文缩写和小数尽量保留为词语。每次 AI 输入最多 4000 字，超出时需分段。

## 本地日志

Debug 构建可按 `[ODict.Local]` 过滤本地词典诊断。`article` 标识同一词条展示，`t` 为诊断初始化后的毫秒数。典型流程为 `route.begin → lookup.begin → lookup.hit → route.local`，在线回退标记 `route.online`。

`ODICT_LOCAL_HTML` 可设为 `off`、`raw`、`document`、`both` 或 `full`。默认 `both` 的每阶段输出上限 256 KiB；`full` 会输出全文，可能包含受版权保护或隐私内容，也会增加控制台开销。`off` 只关闭 HTML 转储，流程日志仍可能含查询词和路径。Release 不包含这些 Debug HTML 转储。

反馈问题时遵循 [贡献指南](../CONTRIBUTING.md)，不要发送未脱敏日志或完整词库。
