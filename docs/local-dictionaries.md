# 本地词典

在设置的“词典来源”中选择 MDX 文件或词典文件夹。每本词典使用独立文件夹时，会关联该目录中的所有 MDD；多 MDX 目录只自动关联同名及数字分卷的 MDD。可以在每本词典的菜单中重新选择全部资源包。

配置立即保存。本地优先模式逐本查询，首次命中停止，全部未命中后访问在线服务。仅在线模式跳过本地文件；中文释义反查目前使用在线服务。候选词先查所有本地词典的精确词头，再按优先级查前缀，最后访问在线候选服务。

## 模块边界

- `LocalDictionary/MDXBinary.swift`：有界二进制读取、zlib 校验解压和 RIPEMD-128 索引解码。
- `LocalDictionary/MDXReader.swift`：利用原文件的词头/正文块目录查找，处理重复词头、跨块正文和内部跳转。
- `LocalDictionary/LocalDictionaryLibrary.swift`：后台串行文件访问、资源寻址及有界内存缓存。
- `LocalDictionary/LocalDictionaryStore.swift`：配置、目录发现与覆盖样式文件创建。
- `LocalDictionary/DictionaryRouter.swift`：来源选择、失败提示、顺序查询与在线兜底。
- `Features/LocalDictionary/`：独立设置组件与本地 HTML 展示，不调用在线词条的原生正文视图。

原始 MDX/MDD 不转换、不修改、不全部解包；不生成外部索引或数据库。配置仅保存路径、名称、资源关联、顺序和启用状态。外置磁盘不可用会显示失败原因并继续查询其他来源。

## 展示调整

添加词典时尝试在词典目录创建 `odict-overrides.css`，已有文件不覆盖。只读目录使用内置的通用默认 CSS。可以自行添加 `odict-overrides.js`；这两个文件在正文加载后附加，下一次查询生效。词典自己的 HTML、CSS、脚本沿用原有引用；不在 Swift 中编写牛津或朗文专用的标签替换、DOM 修补和释义提取规则。

本地正文使用非持久化 WKWebView，以词典 ID 隔离资源地址。资源来自词典目录或关联的 MDD，外部文件的路径和符号链接不能越出目录。页面禁止自动访问网络、嵌入外部页面及提交表单；显式点击外部网页链接交给系统浏览器。没有向页面暴露 Keychain、在线密钥或原生消息桥。MDict `entry://` 等词条链接交给共享查询调度，`sound://` 音频按需读取。

最近记录保留本地词头，暂不从 HTML 提取中文摘要；本地命中不会为了补摘要额外请求在线服务。

## 资源和能力边界

当前支持 MDX/MDD 2.0、未加密或 `Encrypted=2` 的索引、UTF-8/UTF-16LE/GB18030/Big5、未压缩或 zlib 数据块。LZO、注册密码加密和非空内嵌 StyleSheet 替换表会明确报不支持，不冒充词条未命中。词典依赖特定阅读器脚本 API 时，可能需要在该词典的覆盖 JS 中补充行为。

最多保存 32 本词典。读取器 LRU 最多 4 个，采用约 12 MiB 的驻留预算估算；每个读取器只缓存一个小词头块和一个不超过 1 MiB 的正文块。单次压缩/解压块和资源读取有 32 MiB 上限；块目录及词条跳转数量也有上限。该预算不是实际进程内存测量，WKWebView 与解压临时缓冲另有开销。关闭查词窗口释放本地正文、网页视图及读取器缓存。

独立原生验证应用复用生产的 LookupView、本地 HTML 视图和本地设置组件，使用真实 MDX/MDD 与模拟在线数据。实际检查了两本词典的排版、来源、牛津词条跳转、朗文词源展开、发音链接、在线原生释义，以及目录 CSS/JS 覆盖；临时覆盖内容已恢复。设置中的排序、启停、查询模式、移除与文件夹添加已检查，修复了文件夹被过滤后只能进入、无法确认添加的问题，并复验牛津文件夹自动关联两份 MDD。

## 候选词与词典跳转（2026-10-20）

针对 `recoated` 的独立验证确认，当前朗文文件中其原始记录为 `@@@LINK=coat`，`recoating`、`recoats` 也指向 `coat`。`recoagulate` 等相邻候选指向 `coagulate`，`recoat` 未发现独立词头。这些是原文件中的跳转映射，不是界面选中了另一行。

应用分别保存选中的查询词与最终正文词头。本地来源区域在两者不同时显示 `recoated → coat（词典对应词条）`；查询复用和最近记录使用选中的原词，正文 HTML 不做替换。远程词条模型与原生正文视图不变。

经用户同意，执行 `sh scripts/check-candidate-redirects.sh /Volumes/Data/dict`、本地读取器回归及原有查询模型检查，均通过。真实候选检查覆盖点击、键盘、回车、相同目标的不同别名、最近记录、快速切换和零在线调用。独立验证窗口中复现了 `reco` 候选列表及 `recoated → coat` 提示。

## 玻璃背景融合

网页视图关闭独立背景绘制，HTML 和 body 的背景保持透明，共用外层原生玻璃材质，不对正文整体设置 opacity 或再次添加模糊。默认覆盖样式不再在深色模式下铺 `#202124`；CanvasText 和深浅主题变量负责基本文字、次要文字及强调色。对于完全未修改的旧生成模板，读取时提供新的透明模板；用户修改过的 CSS 不自动改写。

朗文原样式中的 `.entry`、`.def` 等固定黑色，以及牛津的例句、音标和内容框颜色，通过各自词典目录中的 `odict-overrides.css` 覆盖。具体词典选择器未加入 Swift；可维护的样式副本放在 `docs/local-dictionary-styles/`。此次更新只替换了本地仍与旧生成模板完全一致的文件，没有覆盖用户自定义样式。

背景融合调整完成源代码与编译交付后，深浅色及不同壁纸下的实际界面效果仍需用户同意后验证；不承诺透明页面能在任意背景下自动获得相同的文字对比度。
