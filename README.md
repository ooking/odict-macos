# ODict for Mac

轻量的原生菜单栏词典。点击菜单栏的书本图标，或使用自己录制的全局快捷键查词。

## 首版功能

- 英文单词、短语查词，输入联想（350ms 防抖）。
- 输入后到候选请求结束显示原生加载指示；候选行支持鼠标悬停高亮，悬停状态仅在该行更新。
- 多候选使用左右布局：左侧选择、右侧预览，自动选中并预览首个词；↑ / ↓ 切换并滚动到可见位置，回车确认。只有一个候选时直接显示释义，隐藏整个候选侧栏和分隔线。
- 搜索框位于顶部，产品图标、名称、设置和更多按钮位于 footer，不显示操作提示。输入法组合输入时保留其按键处理。
- 中文释义反查，英文未命中时给出近似拼写建议。
- 中英文释义、音标、词形变化、标签；释义支持选中复制。
- macOS 系统英语语音朗读。
- 自定义全局快捷键：录制、清除、自动保存及库提供的冲突提示。默认不占用快捷键。
- 最近 20 条成功查词记录，支持清空。
- 独立设置窗口，可配置 HTTPS API 地址和只读 API 密钥；首次启动自动展示设置。
- Escape 收起，点击外部收起，菜单中退出。应用不显示 Dock 图标。

## 技术选择与兼容性

- 原生 Swift + SwiftUI，AppKit `NSStatusItem` / 无边框 `NSPanel` 管理菜单栏及窗口生命周期，没有弹出气泡的顶部尖角。
- macOS 26+ 使用 `NSGlassEffectView` 原生 Liquid Glass；macOS 12–15 回退到 `NSVisualEffectView` 的 `.popover` 材质。遵循系统外观，不固定背景色或强制透明度。
- 最低系统 macOS 12 Monterey；Release 使用 Xcode 标准架构（Intel / Apple Silicon）。实际兼容性仍需对应机器验证。
- Xcode 26+ / Swift 6.2+（本项目源码使用 Swift 5 语言模式，依赖使用 Swift 6.2）。
- 唯一第三方依赖：[KeyboardShortcuts](https://github.com/sindresorhus/KeyboardShortcuts)，通过 Swift Package Manager 固定为 3.1.0。使用其原生录制控件和全局热键注册，不自行监听所有键盘事件。
- `URLSession` + `async/await`；App Sandbox、出站网络权限和 Hardened Runtime。
- 跟随系统深浅色，系统控件、系统字体，未引入网页容器。

## 在 Xcode 打开

1. 打开 `ODict.xcodeproj`，等待 Swift Package Manager 获取 KeyboardShortcuts。
2. 选择 `ODict` scheme 和 `My Mac`。若签名提示需要团队，在 Signing & Capabilities 选择自己的 Team；使用自己的 Bundle ID 分发时也在这里修改。
3. 按 Run。首次运行的设置窗口中，填入只读产品 API 密钥并保存，然后录制全局快捷键。
4. 点击菜单栏书本图标查词。没有配置密钥时，显式查询会提示打开设置。

默认 API：`https://odict-api.touchany.com`，无 `/api` 前缀。密钥在 [ODict API 管理页面](https://odict.touchany.com/admin/api-clients) 创建。不要填写管理密钥。接口契约见相邻 `odict-api/docs/product-api.md`。

设置允许指定其他 HTTPS API 地址；自定义地址应提供同样的产品 API 契约。更换地址时需同时填写新服务的密钥，保存后下一次请求生效。清空密钥并保存会从钥匙串删除密钥。

## 数据与安全

- 只读密钥保存在 macOS Keychain，不写入源码、UserDefaults 或日志。
- API 地址、快捷键、最近查词记录存于 UserDefaults；最近记录仅在本机保存，可通过菜单清空。首版没有云同步。
- 请求使用临时 URLSession，无磁盘响应缓存，不使用 Web Cookie 会话，不跟随重定向，避免把 Bearer 凭据转发给其他站点。
- 不访问剪贴板或其他应用的选中文字，也不要求辅助功能或输入监控权限。
- 不内置开发者共用密钥。当前是用户自带只读密钥的桌面客户端；面向公众发行时，应另行设计用户登录及服务端授权，不能把共享产品密钥打包进客户端。
- HTTP 401/403、404、429、服务错误、超时有对应提示；遵循 Retry-After 提示，不自动反复重试。

## 扩展结构

```text
ODict/App                 菜单栏、窗口、快捷键及应用生命周期
ODict/Models              词条、候选词、DictionaryServing 接口
ODict/Services            产品 API 客户端、Keychain
ODict/Features/Lookup     查词状态、请求取消、最近记录和视图
ODict/Features/Settings   服务设置和快捷键录制
```

界面通过 `LookupModel` 调用 `DictionaryServing`，不直接发请求。输入变化、关闭弹窗及修改服务设置时取消旧查询，并用请求标识阻止过期响应覆盖当前状态。之后可注入离线词典或测试替身。

生词本建议新增独立 `Features/Vocabulary` 和 `VocabularyRepository`，以词条 ID / 单词关联收藏、笔记和复习状态，使用 Core Data / SQLite 持久化；不要把生词数据混入最近查词 UserDefaults。维持 macOS 12 下限时不使用仅较新系统支持的 SwiftData。首次版本尚未实现生词本、划词、离线词库或账号同步。

## 内存与性能原则

以极低内存占用为目标，每次改动都需检查资源生命周期。候选查询复用单个可取消任务，保留 350ms 防抖和旧响应保护；完成或关闭面板时清理任务引用，加载动画只在等待时存在，不增加后台轮询。鼠标悬停使用行内布尔状态，不向整个查词模型发布鼠标移动。语音合成器仅在首次朗读时创建，关闭面板时停止并释放。最近记录限制 20 条，网络响应不设磁盘缓存。

左右布局额外使用一个可取消的释义任务，方向键连续切换按 150ms 防抖；悬停不触发请求。同一个词条正在请求或已经显示时，回车复用该请求或结果。仅保留当前词条，候选最多 10 项，不预取整列词条；自动预览不写入最近记录，仅明确点击或提交时记录。
